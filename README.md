# Hollowmere: Bloodline

A mobile-first, text-based RPG in a single file. Open `index.html` in any browser (or host it on GitHub Pages). Progress auto-saves to the device.

**The loop:** train as a weakling → hunt monsters → join the Lanternwatch Guild → complete contracts → get stronger → die → your heir inherits gold and gear (not levels or skills) and catches up with boosted XP and training.

See the in-game Menu for bloodline history, save export/import and settings.
